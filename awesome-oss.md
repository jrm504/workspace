# Awesome Open Source Recommendations

This is a personal list of recommended open-source projects: projects from the Vietnamese community come first, followed by projects from the global community. The list is not ranked by star count.

> Check each repository's license, maintenance status, and model or dataset terms before using it.

## Vietnamese Open Source Projects

<details>
<summary>AI, Speech, and Language</summary>

- [VieNeu-TTS](https://github.com/pnnbao97/VieNeu-TTS) — On-device Vietnamese text-to-speech with voice cloning, streaming, an OpenAI-compatible API, and LoRA fine-tuning. The latest open-source version in the repository is v3 Turbo.
- [VnCoreNLP](https://github.com/vncorenlp/VnCoreNLP) — A Vietnamese NLP pipeline for word segmentation, part-of-speech tagging, named entity recognition, and dependency parsing; available through Java or a Python wrapper.
- [PhoBERT](https://github.com/VinAIResearch/PhoBERT) — Pre-trained monolingual language models for Vietnamese, designed for a range of downstream NLP tasks.
- [PhoNLP](https://github.com/VinAIResearch/PhoNLP) — A BERT-based multi-task model for Vietnamese part-of-speech tagging, named entity recognition, and dependency parsing.
- [Underthesea](https://github.com/undertheseanlp/underthesea) — An open-source Python toolkit for Vietnamese NLP, now also providing agent components and multiple text-processing APIs.
- [VietOCR](https://github.com/pbcquoc/vietocr) — A Transformer-based OCR library for recognizing text in images, with a focus on Vietnamese.
- [VietVoice-TTS](https://github.com/nguyenvulebinh/VietVoice-TTS) — A Vietnamese text-to-speech library with voice-cloning capabilities.
- [sea-g2p](https://github.com/pnnbao97/sea-g2p) — A grapheme-to-phoneme library for Southeast Asian languages, used by VieNeu-TTS in its pronunciation pipeline.

</details>

<details>
<summary>Data and Databases</summary>

- [Vietnamese Provinces Database](https://github.com/ThangLeQuoc/vietnamese-provinces-database) — SQL, JSON, NoSQL, and GIS datasets for Vietnamese administrative units, including postal codes and boundary data.
- [DBML](https://github.com/holistics/dbml) — A readable markup language for defining and documenting database structures, with a CLI, parser, and supporting tools.

</details>

<details>
<summary>Learning and Documentation</summary>

- [Machine Learning Fundamentals](https://github.com/tiepvupsu/ebookMLCB) — Vietnamese introductory machine-learning materials and notebooks.
- [Machine Learning Systems Design](https://github.com/chiphuyen/machine-learning-systems-design) — A booklet and exercises about designing machine-learning systems in practice.

</details>

## Open Source Projects from the Global Community

<details>
<summary>Operating Systems and Infrastructure</summary>

- [Linux](https://github.com/torvalds/linux) — The open-source kernel at the foundation of Linux and many embedded systems, servers, and devices.
- [Docker](https://github.com/docker/cli) — Tools for packaging, distributing, and running applications in containers.
- [Kubernetes](https://github.com/kubernetes/kubernetes) — A platform for orchestrating container workloads at scale.

</details>

<details>
<summary>Languages and Developer Tools</summary>

- [Git](https://github.com/git/git) — A distributed version-control system widely used for software development.
- [Python](https://github.com/python/cpython) — A general-purpose programming language and its reference implementation in C.

</details>

<details>
<summary>AI and Machine Learning</summary>

- [PyTorch](https://github.com/pytorch/pytorch) — A tensor and deep-learning framework widely used in research and production.
- [Transformers](https://github.com/huggingface/transformers) — A library of pre-trained models for NLP, audio, vision, and multimodal applications.
- [llama.cpp](https://github.com/ggml-org/llama.cpp) — C/C++ inference for large language models, optimized for local execution across a wide range of hardware.

</details>

<details>
<summary>Databases</summary>

- [PostgreSQL](https://github.com/postgres/postgres) — An open-source object-relational database management system.

</details>
