# Technical Documentation

1. Identify the audience, task, prerequisites, and authoritative behavior source.
2. Verify public APIs against implementation and tests; verify broker contracts through the configured Hoalulab documentation MCP.
3. Follow the repository's existing documentation structure, terminology, formatting, and link conventions.
4. Keep examples minimal, executable, safe, and free of real credentials or account data.
5. Distinguish broker-specific behavior and environment constraints explicitly.
6. Run documentation builds, link checks, and executable examples that cover the changed content when available.
7. Report documentation files changed, sources used, validation evidence, and unresolved discrepancies.

Modify documentation files only unless explicitly authorized otherwise. Do not invent behavior to reconcile conflicting sources; report the discrepancy.
